# Mesh Circular Shift Visualizer

## 🔗 Live Demo
**https://mesh-shift-visualizer-b52l.vercel.app/**

## What It Does
Visualizes circular q-shift on a 2D mesh topology in two stages:
- **Stage 1 — Row Shift:** `q mod √p` positions rightward
- **Stage 2 — Column Shift:** `⌊q / √p⌋` positions downward

## Run Locally
```bash
npm install
npm start
```

## Tech Stack
React 18, CSS-in-JS, Google Fonts
